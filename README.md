# 🚀 CloudPocket
CloudPocket is a collaborative transaction tracker designed for the modern user. Unlike traditional apps, CloudPocket allows you to share and manage wallet profiles with friends or family, making group expenses and shared budgets easier to track than ever.
# ✨ Features
- Shared Wallets: Create a profile and invite friends to view or manage transactions together.
- Real-time Tracking: Monitor your spending and income with a sleek, responsive interface.
- Collaborative Management: Manage group funds, travel budgets, or shared household expenses.
- Cross-Platform Ready: Built with a high-performance backend and a modern frontend for a seamless experience.
# 🛠️ Tech Stack
## Frontend
- Next.js: (React Framework) for a fast, SEO-friendly user interface.
- Tailwind CSS: For modern, responsive styling.
- Vercel: Deployment and hosting.
## Backend
- Go Fiber: An extremely fast, Express-inspired web framework for Go.
- GORM: The fantastic ORM library for Golang, handling our database logic.
- Render: Cloud hosting for the backend service.
## Database
- PostgreSQL: Robust, relational data storage for complex wallet relationships.
